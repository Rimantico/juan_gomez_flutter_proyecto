# 📱 Portfolio Flutter - 2º DAM

Proyecto desarrollado en **Flutter** durante el segundo curso del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

Este repositorio funciona como un **portfolio de actividades y ejercicios**, donde se irán incorporando las distintas prácticas realizadas durante el aprendizaje de Flutter y el desarrollo de aplicaciones multiplataforma.

## 🎯 Objetivo

El objetivo del proyecto es poner en práctica los diferentes conceptos aprendidos durante el curso, creando una aplicación que permita acceder de forma organizada a las actividades realizadas.

A medida que avance el curso, el proyecto irá creciendo e incorporando nuevas funcionalidades y ejemplos.

## 🛠️ Tecnologías utilizadas

- **Flutter**
- **Dart**
- **Android Studio / Visual Studio Code**
- **Git**
- **GitHub**

## 📂 Estructura del proyecto

El proyecto está organizado de forma que cada actividad pueda mantenerse separada y accesible desde la aplicación.

La estructura podrá modificarse y ampliarse según las necesidades de las diferentes actividades.

## 🚀 Ejecutar el proyecto

Para ejecutar el proyecto es necesario tener instalado **Flutter**.

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Acceder al proyecto:

```bash
cd nombre-del-proyecto
```

Instalar las dependencias:

```bash
flutter pub get
```

Ejecutar la aplicación:

```bash
flutter run
```
